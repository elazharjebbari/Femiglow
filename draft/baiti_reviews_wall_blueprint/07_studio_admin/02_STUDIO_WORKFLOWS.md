# Workflows Studio

## 1) Modération quotidienne
1. Ouvrir queue PENDING
2. Lire avis + photos
3. Approve ou Reject
4. Si approve: publié immédiatement

## 2) Masquer un avis problématique
1. Filtrer APPROVED
2. Ouvrir avis
3. Action Hide + note

## 3) Créer un avis manuel (support client)
1. Create review
2. Status: APPROVED (si preuve)
3. Tag "Service client" etc.
