# Studio UI - Gestion et modération des avis

## Objectifs
- Ajouter/modifier/supprimer des avis.
- Modérer (approve/reject/hide).
- Tagger et mettre en avant (featured).
- Gérer les photos (ordre, suppression).

## Navigation
- Studio sidebar: "Reviews"
  - Liste
  - Queue modération
  - Tags
  - Paramètres (policy)

## Liste (table)
Colonnes :
- Status (badge)
- Rating
- Produit
- Auteur
- Date
- Has photos
- Verified purchase
- Tags
- Actions (View/Edit)

Filtres :
- status
- product
- rating
- has_photos
- tags
- search (author/body)

## Détail avis
- Preview (comme user)
- Métadonnées
- Photos
- Actions : Approve / Reject / Hide / Delete
- Moderation note

## Policy editor
- Éditer "comment nos avis sont vérifiés"

## UX
- Bulk actions sur queue PENDING.
- Raccourcis clavier (j/k, a=approve, r=reject) option.
