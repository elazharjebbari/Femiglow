# Tone & Style Guide — Voix de marque FemiGlow par langue

> Guide rédactionnel détaillé pour FR, AR et EN. Maintient la voix éditoriale, sobre, intime et féminine de FemiGlow dans les 3 langues. À lire par tout traducteur AVANT d'écrire une seule ligne.

## 1. ADN de la voix FemiGlow (toutes langues)

### 1.1 Six qualités cardinales

| Qualité | Définition | Exemple parlant |
|---|---|---|
| **Sobre** | Pas d'exubérance, pas de superlatifs faciles | "Un kit. Cinq gestes." (pas "Le kit révolutionnaire qui change tout !") |
| **Éditoriale** | Tonale, comme une revue plus qu'une boutique | "Le rituel, en cinq minutes." (pas "Achetez maintenant !") |
| **Intime** | Adresse personnelle, comme à une amie | "Vos ongles, votre temps." (pas "Toutes nos clientes adorent !") |
| **Féminine** | Vocabulaire associé à la délicatesse, au soin | "Une caresse de couleur" (pas "Un blast de pigment") |
| **Non-commerciale** | Pas de pression, pas d'urgence fabriquée | "Disponible." (pas "Plus que 3 en stock — vite !") |
| **Respectueuse** | Du temps, de l'argent, de l'intelligence du lecteur | "À partir de 349 MAD" (pas "Promo folie -50 %") |

### 1.2 Six anti-qualités à bannir

| Anti-qualité | À éviter | Exemple à BANNIR |
|---|---|---|
| Hype | Pas de "révolutionnaire", "incroyable" | "Le vernis qui révolutionne la beauté !" |
| Pressante | Pas de countdown, pas d'urgence | "Plus que 24h !" |
| Familière vulgaire | Pas d'argot, pas de slang | "Trop stylé !" |
| Genre-coded masculin | Pas de termes durs/machos | "Performance ultime" |
| Faux luxe | Pas de mots galvaudés | "Premium", "exclusif", "VIP" |
| Émojis envahissants | Maximum 0 emoji dans le copy marketing | "Découvrez ✨💅🔥" |

### 1.3 Outils stylistiques préférés

- **Phrases courtes**, parfois nominales : "Un geste. Une couleur. Vous."
- **Ponctuation discrète** : pas de point d'exclamation marketing
- **Verbes au présent** : "Le kit arrive." (pas "Le kit va arriver" ou "Recevez !")
- **Anaphores douces** : "Le matin, le rituel. Le soir, la pose."
- **Pauses typographiques** : tirets longs (—), parenthèses sobres
- **Adresse "vous"** par défaut en FR

## 2. Voix française (locale `fr`)

### 2.1 Niveau de langue

- **Soutenu mais accessible** — éviter le jargon, mais ne pas tomber dans le familier
- **"Vous" par défaut** — respect, distance professionnelle légère, intimité ressentie sans familiarité
- **"Tu" exceptionnel** — uniquement dans des copys spécifiques (campagnes Instagram, audience jeune ciblée), jamais sur le site principal

### 2.2 Choix lexicaux

| Préférer | Éviter | Pourquoi |
|---|---|---|
| Le kit | Le pack | "Pack" est commercial, "kit" est neutre |
| Le rituel | La routine | "Routine" est hygiéniste, "rituel" est éditorial |
| La pose | L'application | "Pose" est plus délicat |
| La maison | La marque | "Maison" évoque luxe sobre français |
| La couleur | La teinte | "Teinte" est correct mais moins chaleureux |
| Le geste | L'étape | "Geste" est plus humain |
| Un soin | Un produit | "Produit" est froid |
| Découvrir | Acheter | Sauf en CTA explicite |
| Recevoir | Profiter | "Profiter" sonne commercial |
| Choisir | Sélectionner | "Sélectionner" est froid |

### 2.3 Tournures éditoriales

**OK :**
- "Le rituel, en cinq minutes."
- "Un kit pensé pour vous."
- "Trois gestes. Une couleur. Vos ongles."
- "Disponible en livraison à domicile."

**KO :**
- "Vivez l'expérience FemiGlow ! 💅✨"
- "Notre kit révolutionnaire change la donne"
- "Achetez maintenant et profitez de -20 % !"
- "Cliquez ici pour découvrir notre collection"

## 3. Voix arabe (locale `ar`)

### 3.1 Registre

**Décision** : **arabe standard moderne (MSA, الفصحى المبسطة)** comme base, avec **touches de darija marocaine** uniquement dans des copys ciblés (newsletter saisonnière, campagne Instagram).

| Surface | Registre |
|---|---|
| Site principal (marketing, kit, rituel, journal) | MSA simplifié |
| Pages légales | MSA strict |
| Wizard checkout | MSA simplifié |
| Newsletter / email transactionnel | MSA |
| Campagne Instagram | MSA + touches darija OK |
| Support clientèle | MSA, darija OK si demande client |

### 3.2 Pourquoi MSA (pas darija intégrale)

| Argument | Détail |
|---|---|
| Lisibilité écrit | MSA est universellement lisible par tout arabophone (Maroc, Algérie, expat, Levant) |
| Sérieux marque | Darija écrite est associée à l'informel SMS, casse l'éditorial |
| SEO arabe | Google index meilleur MSA |
| Documents légaux | Obligatoire MSA pour CGV / mentions légales |
| Cohérence | Une seule norme évite la dérive |

### 3.3 Pourquoi touches de darija (par moments)

| Argument | Détail |
|---|---|
| Authenticité | FemiGlow est marocaine — la darija crée un lien |
| Newsletter ciblée | Une note "salam, kifaki" en ouverture rapproche |
| Différenciation | Marques internationales restent en MSA pur, FemiGlow peut signer |

### 3.4 Choix lexicaux AR

| Concept | Préférer (MSA) | Éviter | Notes |
|---|---|---|---|
| Le kit | الكيت | المجموعة | "Kit" est emprunt accepté, plus chic |
| Le rituel | الطقوس / الطقس | الروتين | "Routine" est anglicisme |
| La maison | المنزل / دار | البيت (familier) | "دار" très évocateur marocain |
| Les ongles | الأظافر | (peu d'alternatives) | |
| Le vernis | الطلاء / طلاء الأظافر | (terme technique sans alternative) | |
| La couleur | اللون | الصبغة | Standard |
| Le geste | الحركة / اللمسة | الخطوة | "Touche" évoque délicatesse |
| Madame | سيدتي | (terme respectueux) | |
| Découvrir | اكتشفي | (verbe féminin singulier) | Adresse cliente femme |
| Composer | أنشئي | (verbe féminin singulier) | |
| Recevoir | استلمي | (verbe féminin singulier) | |

### 3.5 Adresse genrée féminine

L'arabe genre les verbes et les pronoms. **FemiGlow s'adresse aux femmes** → utiliser systématiquement la forme **féminine singulière** ("أنتِ"/anti = "tu" féminin, ou forme polie féminine).

| Forme | Usage |
|---|---|
| Tu féminin (أنتِ) | Adresse intime, newsletter, Instagram |
| Verbe à l'impératif féminin (اكتشفي, اختاري) | CTAs |
| Forme polie féminine | Wizard, support, légal |

⚠️ Ne pas utiliser la forme masculine par défaut (erreur fréquente des traductions automatiques).

| FR | MSA standard | Touche darija OK |
|---|---|---|

→ Touches **rares**, par doses homéopathiques. Jamais en pleine page produit.

### 3.9 Spécificités typographiques

- **Pas de tashkeel** (voyelles courtes) dans le marketing — alourdit visuellement
- **Chiffres occidentaux** (1, 2, 3) pour prix, dates, numéros — convention Maroc
- **Pas de tracking-* CSS** — casse les ligatures
- **Police Cairo** (cf. `typography.md`) — sobre, lisible

## 8. Pluriels et nombres

### 8.1 FR — règles simples

- 0 et 1 : singulier ("0 article", "1 article")
- 2+ : pluriel ("2 articles")

```ts
itemsCount: (n) => `${n} article${n > 1 ? 's' : ''}`
```

### 8.2 AR — règles complexes

L'arabe a 6 formes de pluriel selon la quantité (zero, one, two, few, many, other) selon CLDR.

```ts
itemsCount: (n) => {
  if (n === 0) return 'لا منتجات';
  if (n === 1) return 'منتج واحد';
  if (n === 2) return 'منتجان';
  if (n >= 3 && n <= 10) return `${n} منتجات`;
  if (n >= 11) return `${n} منتجا`;
  return `${n} منتج`;
};
```

→ Implémentation via ICU MessageFormat dans next-intl :

```json
"items_count": "{count, plural, =0 {لا منتجات} =1 {منتج واحد} =2 {منتجان} few {# منتجات} many {# منتجا} other {# منتج}}"
```

### 8.3 EN — règles simples

- 0 et 2+ : pluriel
- 1 : singulier

```ts
itemsCount: (n) => `${n} item${n !== 1 ? 's' : ''}`
```

## 9. Devises et formats

### 9.1 Prix MAD

| Locale | Format |
|---|---|
| FR | `349 MAD` ou `349,00 MAD` |
| AR | `349 درهم` ou `349 MAD` (les deux acceptés) |
| EN | `MAD 349` ou `349 MAD` |

Implémentation `Intl.NumberFormat` :

```ts
new Intl.NumberFormat('fr-MA', { style: 'currency', currency: 'MAD' }).format(349);
// → "349,00 MAD"

new Intl.NumberFormat('ar-MA', { style: 'currency', currency: 'MAD' }).format(349);
// → "349,00 د.م.‏" (avec marker RTL invisible)

new Intl.NumberFormat('en-US', { style: 'currency', currency: 'MAD' }).format(349);
// → "MAD 349.00"
```

### 9.2 Dates

| Locale | Format court | Format long |
|---|---|---|
| FR | `27/05/2026` | `27 mai 2026` |
| AR | `27/05/2026` | `27 ماي 2026` |
| EN | `05/27/2026` ou `27/05/2026` | `May 27, 2026` |

Implémentation :

```ts
new Intl.DateTimeFormat('fr-FR', { dateStyle: 'long' }).format(new Date());
// → "27 mai 2026"
```

## 11. Anti-patterns transverses

- ❌ **Traduction littérale machine** sans relecture humaine
- ❌ **Pluriels écrasés** en arabe ("3 منتج" au lieu de "3 منتجات")
- ❌ **Genre masculin par défaut** en arabe (FemiGlow s'adresse aux femmes)
- ❌ **"Bonjour" → "Hi"** (trop décontracté pour FemiGlow EN)
- ❌ **Emojis dans le copy site** (réservés Instagram à la rigueur)
- ❌ **Marketing pressant** ("Hurry!", "Last chance!", "خصم محدود !")
- ❌ **Familier vulgaire** ("Trop bien", "زوين بزّاف", "Super cool")
- ❌ **Anglicismes inutiles en FR** ("Booster", "Mood", "Vibe")
- ❌ **Anglicismes inutiles en AR** ("روتين" au lieu de "طقوس")
- ❌ **Mot "premium" / "luxe"** — sous-entendu, jamais affirmé
- ❌ **CTA à l'impératif sec** ("Achetez !", "اشتري !", "Buy!")
- ❌ **Tutoiement français** sur le site principal (exception Instagram)
- ❌ **MSA + darija mélangés en plein paragraphe** (choisir l'un ou l'autre par surface)

## 12. Workflow de validation traduction

### 12.1 Étapes

| # | Étape | Responsable |
|---|---|---|
| 1 | Source FR rédigée par copywriter / fondatrice | Interne |
| 2 | Brief envoyé à traducteur (cf. brief template section 12.2) | Lead i18n |
| 3 | Traduction AR / EN livrée | Traducteur natif |
| 4 | Relecture par 2e traducteur natif (4 yeux) | Reviewer indépendant |
| 5 | Validation in-context (Crowdin / Lokalise screenshot mode) | Lead i18n |
| 6 | Test sur staging par utilisateur natif | Tester arabophone / anglophone |
| 7 | Ship | Lead i18n |

### 12.2 Brief template à donner au traducteur

```
PROJET : FemiGlow — traduction FR → [AR/EN]
TYPE : copy marketing / wizard / légal / email

CONTEXTE :
- Marque marocaine haut de gamme féminine
- Voix : sobre, éditoriale, intime, non-commerciale
- Ton : « comme une revue », pas comme un site e-commerce

CONTRAINTES :
- Préserver les noms de marque (FemiGlow, Maison, Kit)
- Adresse féminine en AR (verbes féminins)
- Pas d'emojis
- Pas de superlatifs commerciaux
- Glossaire fourni (content-style-guide.csv)

LIVRABLES :
- Fichier JSON avec mêmes clés que source FR
- Notes sur les choix lexicaux discutables
- Verbatim alternatives si plusieurs options envisagées

DEADLINE : [date]
PAIEMENT : [montant] au mot source
```
