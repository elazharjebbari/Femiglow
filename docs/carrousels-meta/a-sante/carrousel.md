# Carrousel A — Manucure régénératrice

> *Angle santé. La manucure japonaise comme **soin** des ongles, pas comme parure.*

---

## 1. Identité

| Attribut                 | Valeur                                                                                                                |
| ------------------------ | --------------------------------------------------------------------------------------------------------------------- |
| Slug                     | `a-sante`                                                                                                              |
| Promesse en une phrase   | « Tes ongles ne se cachent plus, ils se réparent. »                                                                   |
| Bénéfice central         | Régénération naturelle de la kératine, sans peinture, sans UV, sans abrasion.                                          |
| Audience principale      | Femmes 28-45 ans, urbaines, CSP B/B+, Maroc. Lassées du vernis semi-permanent, attentives à leur santé / clean beauty. |

## 2. Positionnement neuromarketing

### 2.1 Frein dominant à lever

> *« J'ai peur que ça ne marche pas — ou que ce soit encore un truc beauté qui abîme à long terme. »*

### 2.2 Levier dominant

**Authority by transparency** (Slovic 1995) — la composition est
montrée nue, sans euphémisme. La cliente conclut elle-même.

### 2.3 Leviers secondaires

- **Loss aversion** (Kahneman & Tversky) : slide 5 montre l'ongle
  fragilisé par le semi-permanent (sans agressivité), pour
  contraster avec l'ongle restauré.
- **Goal gradient** (Kivetz) : numérotation discrète `1—8` qui
  monte avec l'engagement.
- **Sensory imagery** (Krishna 2012) : « lisser », « polir »,
  « préparer », « révéler » — quatre verbes tactiles.
- **Numerical fluency** (Wadhwa & Zhang) : chiffres précis pour
  ancrer la rationalité (« 5 minutes », « 4-6 semaines »).
- **Endowment effect** (Thaler) : « tes ongles » dès la slide 1.
- **Cognitive ease** (Kahneman) : une idée par slide, palette
  réduite à 3 couleurs (crème, encre, sauge).

## 4. Slide 1 — Cover

### Objectif
Hook. Provoquer l'arrêt du scroll en moins d'une seconde. CTR
slide 1 → slide 2 cible : ≥ 65 %.

### Visuel
Une main féminine à carnation moyenne, posée à plat sur un
papier de lin crème, ongles courts à moyens, cuticules nettes,
**pas de vernis**, lumière du matin. Plan rapproché 50 mm,
profondeur de champ faible. La main occupe 60 % du cadre, espace
négatif au-dessus pour le titre.

### Texte sur l'image

```
[en haut, Pinyon Script, petit] FemiGlow

[au-dessus de la main, Cormorant Garamond Light]
Et si tes ongles
n'avaient pas besoin
d'être cachés ?
```

### Mécanique cognitive

- **Pattern interrupt** : sur Instagram, dominent les ongles
  vernis. Une main *nue* surprend.
- **Rhetorical question** (Burnkrant & Howard) : la question
  oblige à un petit effort cognitif → mémorisation.
- **Endowment** : « tes ongles » immédiatement.
- **Cognitive ease** : 13 mots. Une idée.

### Variantes hook à tester (3)

| ID    | Texte                                                  |
| ----- | ------------------------------------------------------ |
| H1-A  | Et si tes ongles n'avaient pas besoin d'être cachés ?   |
| H1-B  | Cinq minutes. Quatre gestes. Aucune peinture.            |
| H1-C  | Le rituel japonais qui répare au lieu de couvrir.       |

> H1-A est le défaut. H1-B est plus rationnel (numerical fluency).
> H1-C nomme « japonais » plus tôt — utile si l'audience est en
> phase exploratoire.

## 5. Slide 2 — Tension

### Objectif
Nommer le constat sous-jacent (le vernis cache un ongle qu'on n'a
plus envie de regarder), sans culpabiliser. Ouvrir l'envie de
réparation.

### Visuel
Diptyque vertical : en haut, deux ongles abîmés (légères stries,
décollement subtil) avec reste de vernis semi-permanent ;
en bas, les mêmes ongles **retirés du vernis**, un peu fragilisés,
nus. Lumière douce, pas de jugement.

### Texte sur l'image

```
[en haut, Inter italic, petit, brume]
LE CONSTAT

[centre, Cormorant Garamond Light]
Le vernis cache.
Le rituel répare.
```

### Mécanique cognitive

- **Loss aversion** : visualiser la perte (ongle fragilisé) avant
  la solution.
- **Antithèse rhétorique** : structure binaire « cache / répare »
  fixe la mémoire.
- **Slow framing** (Luxury) : pas de croix rouge, pas de flèche.
  Le contraste fait le travail.

## 6. Slide 3 — Promesse

### Objectif
Présenter le rituel comme un héritage — sans encore le détailler.
Crée l'attente du « comment ».

### Visuel
Trois pots de verre dépoli alignés sur papier crème, couvercles
champagne mat, contenus visibles : poudre fine, résine ambre,
herbe sauge. 50 mm, focus central. Espace négatif important au-
dessus.

### Texte sur l'image

```
[au-dessus des pots, Inter italic, petit, brume]
UNE MÉTHODE JAPONAISE

[centre haut, Cormorant Garamond Light]
Quatre gestes
qui prennent
soin de l'ongle.

[bas, Inter regular, petit]
1 — 8
```

### Mécanique cognitive

- **Authority via origin** : « japonaise » = patrimoine
  séculaire, autorité tacite.
- **Mystery box** (Loewenstein) : on annonce 4 gestes mais on les
  retient pour la slide 4.
- **Rule of three visuel** : 3 pots = stabilité visuelle.

## 7. Slide 4 — Démonstration

### Objectif
Livrer la promesse de la slide 3 : nommer les 4 gestes, montrer
leur logique. La cliente comprend en lecture rapide.

### Visuel
Grille 2 × 2 macro : 4 micro-photos centrées sur chaque pot avec
son geste implicite (pinceau pour paste, buffer mousseline pour
powder, linge coton pour shine, chiffon soie pour polish).
Surfaces papier crème.

### Texte sur l'image

```
[en haut, Inter italic, petit, brume]
LE RITUEL

[grille — chaque cellule]
paste
Préparer.
─
powder
Lisser.
─
shine
Polir.
─
polish
Révéler.

[bas]
Cinq minutes.
```

### Mécanique cognitive

- **Sensory imagery** (Krishna) : 4 verbes tactiles activent
  zones sensori-motrices.
- **Parallel individuation** : 4 éléments distincts perçus
  simultanément (≤ limite cognitive de 4-7).
- **Mere exposure** : ces 4 verbes sont aussi présents sur le site
  → cohérence cross-canal qui consolide.
- **Numerical fluency** : « cinq minutes » précis.

## 8. Slide 5 — Preuve avant / après

### Objectif
Apporter la preuve visuelle. Le frein « est-ce que ça marche
vraiment ? » tombe en moins de deux secondes.

### Visuel
Diptyque carré : à gauche, une main au jour 1 — ongles courts,
légèrement fragilisés, surface mate. À droite, **la même main**
au jour 21 — ongles plus uniformes, cuticules nettes, brillance
naturelle (pas de vernis, pas de gloss). Même surface, même
lumière, même cadrage. La crédibilité tient à l'identité du
contexte.

### Texte sur l'image

```
[au-dessus, Inter italic, petit, brume]
APRÈS 21 JOURS

[entre les deux photos, Cormorant Garamond Light italic]
même main.
sans peinture.
```

### Mécanique cognitive

- **Concrete vivid information** (Nisbett & Ross 1980) : preuve
  saillante > argument abstrait.
- **Authority by transparency** : pas de retouche, lumière
  identique. Pas de flèche, pas d'étoile « résultat garanti ».
- **Restraint éditorial** : « 21 jours » sans superlatif.
  Le chiffre suffit.

### Disclaimer Meta intégré

Sous la slide, en métadonnée du carrousel (champ description) :
« Témoignage individuel. Les résultats varient selon la routine. »

## 9. Slide 6 — Composition

### Objectif
Désamorcer le risque physique / sanitaire / écologique. La
composition est listée brute — la cliente conclut elle-même que
c'est sain.

### Visuel
Plat lay top-down : cinq petites coupelles de céramique non vernie,
chacune contenant une matière première : kaolin, poudre de bambou,
résine de pin, huile de jojoba, cire de carnauba. Étiquettes
manuscrites discrètes sur papier kraft, alignement régulier.
50 mm, lumière diffuse, ombres courtes.

### Texte sur l'image

```
[haut, Cormorant Garamond Light]
Cinq matières.
Aucune peinture.

[liste centrée, Inter regular, petit, encre]
kaolin · bambou · résine de pin · jojoba · carnauba

[bas, Inter italic, petit, brume]
sans formaldéhyde · sans toluène · sans phtalates
```

### Mécanique cognitive

- **Specificity wins** : 5 ingrédients listés = preuve > « clean
  beauty ».
- **Authority by transparency** (Slovic) : montrer ce qui est
  > clamer ce qui n'est pas.
- **Negation power** (Wegner — *don't think of a white bear*) :
  les trois exclusions explicites en bas activent justement les
  sceptiques.

## 10. Slide 7 — Réassurance

### Objectif
Lever les freins « je ne saurai pas faire » et « ça va prendre
trop de temps ».

### Visuel
Une main détendue, paume vers le bas, posée sur un linge de lin
froissé. À côté, un sablier en verre avec sable couleur sauge,
petit, ressort discret. Plan moyen, lumière du matin.

### Texte sur l'image

```
[Cormorant Garamond Light]
Cinq minutes,
toutes les six semaines.

[Inter regular, petit, encre]
Un sablier inclus.
Une notice illustrée.
Aucune lampe UV.
```

### Mécanique cognitive

- **Numerical anchoring** : 5 min vs ~30 min de pose vernis.
- **Risk reversal implicite** : on dit ce que la maison fournit
  (« inclus ») → la cliente sait ce qu'elle reçoit.
- **Loss aversion inversée** : « aucune lampe UV » réactive le
  doute du semi-permanent (UV = controversé).

## 11. Slide 8 — CTA

### Objectif
Convertir. Slide vue par 28 % minimum des impressions, ROAS
porte sur ce moment.

### Visuel
Cadre crème, fond plein, espace négatif important. Au centre, le
**Kit Rituel d'Éclat** — trois pots alignés sur un cube de papier
épais. Pas de halo, pas de surbrillance. Lumière du matin.

### Texte sur l'image

```
[haut, Pinyon Script]
FemiGlow

[centre, Cormorant Garamond Light]
Recevoir le rituel.

[en-dessous, Inter regular, petit]
Kit Rituel d'Éclat — 320 MAD
livraison Maroc · paiement à la livraison
retour libre 14 jours

[bas, Inter italic, petit, brume]
femiglow.ma/kit
```

### Mécanique cognitive

- **Anchoring de prix** (Kolenda *Pricing*) : le prix arrive
  **après** la valeur, jamais avant.
- **Risk reversal** : 3 réassurances en une ligne.
- **Goal gradient** (Kivetz) : la slide 8 récompense l'effort de
  swipe, le CTA est doux et mérité.
- **Restraint** (*Luxury*) : pas de bouton, pas de néon. Le tap
  Meta « En savoir plus » suffit.

### Variantes CTA à tester (3)

| ID    | Texte                          |
| ----- | ------------------------------ |
| C8-A  | Recevoir le rituel.             |
| C8-B  | Commencer mon rituel.           |
| C8-C  | Découvrir le kit.               |

> C8-A est le défaut (lexique « recevoir » = voix maison).
> C8-B est plus possessif (endowment renforcé).
> C8-C est plus exploratoire (audience froide).

## 12. Plan A/B test

### Phase 1 — 7 jours

| Variable testée                 | Variantes              | Métrique de décision |
| ------------------------------- | ---------------------- | -------------------- |
| Slide 1 (hook)                  | H1-A / H1-B / H1-C     | CTR slide 1 → slide 2 |
| Slide 8 (CTA)                   | C8-A / C8-B / C8-C     | Conversion post-clic  |

3 × 3 = 9 combinaisons → simplifier en **3 ad sets** :
- **Combo 1** (défaut) : H1-A + C8-A
- **Combo 2** (rationnel) : H1-B + C8-A
- **Combo 3** (possessif) : H1-A + C8-B

### Phase 2 — 14 jours

Garder le combo gagnant, tester variantes de slide 5 (preuve) :
- 5-A : main A (carnation moyenne)
- 5-B : main B (carnation foncée)

Pour signal d'inclusivité local Maroc.
