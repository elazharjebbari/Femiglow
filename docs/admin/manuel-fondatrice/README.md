# Manuel fondatrice — Console admin FemiGlow

Bienvenue. Ce manuel s'adresse à toi, fondatrice et utilisatrice
principale de la console d'administration FemiGlow. Il est volontairement
court et accessible : si tu sais utiliser une boîte mail, tu sauras
utiliser la console.

## Adresse de la console

- Production : https://femiglow.ma/admin
- Preview (tests) : https://staging.femiglow.ma/admin

## Tes identifiants

Tes identifiants sont stockés dans le coffre **1Password vault « FemiGlow Ops »**.
Ne les partage **jamais** par email, Slack ou WhatsApp. Si tu as un doute
sur le fait que quelqu'un les ait obtenus, va directement à
[En cas de problème](05-en-cas-de-probleme.md) §1 (rotation de mot de
passe).

## Le ton de cette console

La console reprend la voix FemiGlow : tutoiement, vocabulaire chaud,
zéro jargon technique. Les actions destructrices (supprimer un endpoint,
révoquer un secret) demandent toujours une confirmation explicite.
