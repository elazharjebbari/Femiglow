# 01 — Marque, vision et voix

> *Pourquoi la maison existe · Comment elle parle · Comment elle se tient*

---

## 1. Vision et mission

**Vision** : devenir, en cinq ans, la référence de soin lent pour les ongles dans le monde arabe et francophone — une maison qui transmet un rituel plus qu'elle ne vend un produit.

**Mission** : offrir aux femmes occupées un retour à la patience à travers un soin manucure de quatre minutes, sans vernis, sans abrasion, transmis d'une main à l'autre.

## 2. Promesse centrale

> *Le rituel d'éclat. Quatre gestes. Une main qui retrouve sa lumière, sans vernis ni abrasion.*

Cette promesse fonctionne sur trois niveaux :

| Niveau | Ce qui est dit | Ce qui est implicite |
|---|---|---|
| **Sensoriel** | « éclat », « lumière » | la beauté ne s'ajoute pas, elle se révèle |
| **Méthodique** | « quatre gestes » | le rituel est appris, pas magique |
| **Éthique** | « sans vernis ni abrasion » | refus du raccourci cosmétique |

## 3. Positionnement

| Axe | Position FemiGlow | Antithèse |
|---|---|---|
| **Marché** | Soin lent pour les ongles | Vernis · semi-permanent · nail art |
| **Tonalité** | Maison, complicité | Marque, transaction |
| **Cliente** | Initiée | Consommatrice |
| **Objet vendu** | Rituel | Produit |
| **Promesse** | Indirect (suggestion) | Direct (slogan) |
| **Durée** | Lent, patience | Express, urgence |

## 4. Trois piliers identitaires

### 4.1 Le rituel comme grammaire

Chaque page raconte un fragment du rituel : la **préparation** (page Maison), le **geste** (page Rituel), la **patience** (page Journal), l'**éclat** (page Kit / Merci). L'ensemble du site est une chorégraphie cohérente.

### 4.2 L'absence comme signature

Ce que la maison **refuse** définit son luxe :

- Pas de pop-up, pas de countdown, pas d'emoji
- Pas de réduction-coupon, pas de soldes, pas de « offre flash »
- Pas de point d'exclamation
- Pas de visage humain dans les visuels (mains, gestes, détails uniquement)
- Pas de musique sur les vidéos (silence ambiant, frottements, tintements rares)
- Pas de jargon SaaS / e-commerce générique

### 4.3 Une maison, deux portes

| Univers | Tonalité | Couleur dominante | Vocabulaire |
|---|---|---|---|
| **B2C** (rituel) | Sensorielle, contemplative, complice | Sauge 60 % palette riche | « initiée », « rituel », « éclat » |
| **B2B** (programme) | Factuelle, précise, partenariale | Crème 70 % palette épurée | « partenaire », « marge », « MOQ » |

Pas de bichromie radicale entre les deux : **même famille, deux dosages contextuels**.

## 5. Persona principale (B2C)

**Salma · 34 ans · Casablanca · Directrice de communication**

- Urbaine, CSP B+, équipée iPhone, lectrice de magazines lifestyle (Vogue Arabia, Femme Magazine)
- Pratique la beauté depuis l'adolescence mais commence à se lasser des semi-permanents
- Recherche : un soin qui « ne triche pas », qui prend du temps mais qui en mérite
- Mode de découverte : Instagram (story d'amie), Google search « soin ongles naturel »
- Peurs : que ce soit *encore* un produit lifestyle vide de substance, que ça abîme ses ongles, que ce soit cher pour rien
- Déclencheurs : récit fondateur authentique, ingrédients tracés, témoignages d'initiées (pas d'influenceuses)

## 6. Lexique de la maison

### 6.1 On dit ✅

| Mot | Sens / Usage |
|---|---|
| **rituel** | geste lent, intentionnel, transmis |
| **éclat** | lumière qui revient — pas neuf, pas brillant |
| **précision** | les quatre étapes, pensées |
| **naturel** | sans paraben, sans abrasion |
| **connaisseuse** | celle qui sait, sans afficher |
| **révéler** | faire apparaître ce qui était déjà là |
| **patience** | le temps comme ingrédient |
| **complice** | ton entre soi, jamais commercial |
| **partenaire** | salon, institut (jamais « client B2B ») |
| **découvrir** | verbe d'ouverture (jamais « acheter ») |
| **maison** | jamais « marque » |
| **initiée** | cliente ayant complété le rituel |
| **avec soin** | closing récurrent |

### 6.2 On évite ❌

| Mot | Pourquoi |
|---|---|
| **vernis** | la maison n'en pose pas — le mot trahit |
| **ongles parfaits** | perfectionnisme ≠ maison |
| **nail art** | registre fashion, pas rituel |
| **révolutionnaire**, **incroyable**, **wow** | superlatif cheap luxury |
| **offre flash**, **dépêchez-vous** | urgence ≠ rituel |
| **girls** | la maison parle aux femmes |
| **clientes B2B** | dire **partenaires** |
| **deal**, **promo**, **soldes** | jamais |
| **Acheter maintenant**, **Add to cart** | dire « Recevoir le rituel » |
| **Bienvenue !** (avec exclamation) | jamais d'exclamation |

## 9. Posture sur les sujets sensibles

| Sujet | Position de la maison |
|---|---|
| **Comparaison vernis** | Honnête : le vernis dure plus longtemps, le rituel respecte plus l'ongle. Choix de philosophie, pas de performance. |
| **Prix (320 MAD)** | Affiché rond, sans barré, sans countdown. Justifié par sourcing, durée du rituel, packaging artisanal. |
| **Délai livraison** | Estimé honnêtement (3-5 j standard, 1-2 j express). Jamais « livraison instantanée ». |
| **Avis** | Témoignages textes, mention « initiée depuis [mois année] » (trajectoire > note plate). Pas d'étoiles. |
| **Réseaux sociaux** | Présence Instagram + LinkedIn pro, pas de TikTok V1. Jamais de tendance virale. |
| **Influenceurs** | Refus de partenariat rémunéré ; à la place, envois discrets sans contrepartie obligatoire. |

## 10. Charte des images

| Type | Règle |
|---|---|
| **Visages** | Jamais de visage de plein face. Mains, gestes, détails, silhouettes seules autorisés. |
| **Lumière** | Naturelle, latérale, golden hour. Pas de flash, pas de studio agressif. |
| **Décor** | Marbre, lin écru, bois clair, café, fenêtre lumineuse. Casablanca en arrière-plan implicite. |
| **Cadrage** | Resserré, contemplatif. Vidéos en ralenti (300-400 ms perception slow motion). |
| **Édition** | Couleurs naturelles, jamais saturées. Pas de filtre Instagram. |
| **Format** | 4:3 ou 4:5 portrait, jamais carré social media. |
