# Annexe — Glossaire éditorial FemiGlow

> *Le vocabulaire de la maison. À consulter à chaque microcopy, chaque titre, chaque mail.*

---

## 1. Lexique de marque

### À utiliser

| Mot | Domaine | Note |
|---|---|---|
| **rituel** | usage | mot pivot, employer aussi souvent que naturel |
| **geste** | action | un geste = une étape du rituel |
| **maison** | marque | « la maison FemiGlow », « notre maison » |
| **saison** | calendaire | rythme du contenu et des produits |
| **patience** | valeur | antithèse de la précipitation e-commerce |
| **soin** | produit | « notre soin », pas « notre formule » |
| **silence** | qualité | qualité d'écoute, de lenteur |
| **lente** | rythme | « beauté lente », « écriture lente » |
| **transparent / transparence** | matière + valeur | sourcing, communication |
| **artisanat** | production | jamais « industrie » |
| **discret / discrétion** | esthétique | pas de tape-à-l'œil |
| **ancré / ancrage** | territorial | enracinement marocain |
| **tenue** | qualité | « tenue parfaite », tient dans le temps |
| **respiration** | rythme typographique et de page |
| **lumière** | esthétique | pas de « brillance » ni « éclat » |
| **précis / précision** | geste | qualité du soin |
| **sensible** | émotion | pas « émotionnel » |
| **cérémonie** | usage | sans connotation religieuse, registre soin |

### À éviter (ou interdire)

| Mot | Pourquoi |
|---|---|
| ❌ acheter | trop transactionnel — préférer « adopter », « accueillir », « commander » |
| ❌ produit | trop générique — préférer « soin », « rituel », « kit » |
| ❌ client | trop transactionnel — préférer « visiteuse » (interne), prénom (email) |
| ❌ stock, rupture | pas en avant — préférer « bientôt » |
| ❌ promotion, solde, bon plan | jamais |
| ❌ marketing, conversion, funnel | jamais en frontal |
| ❌ wow, magique, incroyable | jamais |
| ❌ tendance, must-have, hype | jamais |
| ❌ urgence, vite, dépêchez-vous | contraire de la marque |
| ❌ exclusif, premium, luxueux | montrer plutôt que dire |
| ❌ révolutionnaire, innovant | jamais |
| ❌ secret de beauté | trop magazine |
| ❌ détoxifier, purifier (claims santé) | pas pertinent + contraintes légales |
| ❌ ! (point d'exclamation) | jamais |
| ❌ emoji | jamais |
| ❌ ALL CAPS | seulement Kicker, jamais paragraphe |

## 3. Confirmation et statut

| Cas | Phrase |
|---|---|
| Newsletter inscrite | *« Vous êtes inscrite. Premier billet à venir. »* |
| Form contact envoyé | *« Votre message est arrivé. Nous écrirons sous trois jours. »* |
| Commande confirmée | *« Votre commande est confirmée. Vous recevrez un email de suivi. »* |
| Email de bienvenue | *« Bienvenue dans la maison. »* |
| Email expédition | *« Votre rituel a quitté la maison. Suivi : [...] »* |
| Email J+5 (rituel) | *« Cinq jours. Premiers gestes. »* |
| Email J+15 (récurrence) | *« Une saison passe. Comment vont vos ongles ? »* |

## 4. Erreurs (forms)

| Champ / contexte | Message |
|---|---|
| Email invalide | *« Cette adresse email semble incorrecte. »* |
| Email manquant | *« L'email est nécessaire pour la confirmation. »* |
| Téléphone Maroc invalide | *« Le numéro doit commencer par +212 ou 0. »* |
| Code postal invalide | *« Code postal à 5 chiffres. »* |
| Champ obligatoire vide | *« Ce champ est nécessaire. »* |
| Carte refusée Stripe | *« Le paiement n'a pas abouti. Vérifiez vos informations ou essayez une autre carte. »* |
| Erreur réseau | *« La connexion s'est interrompue. Vos informations sont conservées. »* |
| Limite atteinte (rate-limit) | *« Trop de tentatives. Réessayez dans 5 minutes. »* |
| Captcha échoué | *« Vérification humaine. Réessayez. »* |
| Stock indisponible | *« Le rituel est en préparation. Bientôt de retour. »* |

## 5. Pages d'erreur

### 404

```
Cette page n'existe plus dans la maison.

[ Retourner à l'accueil ]
[ Découvrir le rituel ]
[ Voir le journal ]
[ Visiter la maison ]
```

### 500

```
Un imprévu.

Notre équipe est prévenue. La page reviendra rapidement.

[ Recharger la page ]
[ Retourner à l'accueil ]
```

## 7. Dénominations internes

| Ce qu'on appelle | Ce qu'on évite |
|---|---|
| **Le rituel** | « Le produit principal », « Le kit » (sauf en page `/kit`) |
| **La maison** | « L'entreprise », « La marque », « La société » |
| **Le journal** | « Le blog », « Les actualités », « Le magazine » |
| **La saison** | « La collection », « La gamme » |
| **Visiteuse / lectrice** (en interne) | « Cliente », « User », « Acheteuse » |
| **Salma** | persona type, prénom symbolique |
| **Casablanca** | toujours nommée, jamais « le Maroc » seul |
| **Dirhams (MAD)** | jamais « DH » abrégé en frontal, mais accepté en récap technique |
| **Cinq minutes** | mantra du rituel, à écrire en lettres |
| **Trois gestes** | autre invariant, à écrire en lettres |

## 8. Typographie françaises

| Règle | Exemple |
|---|---|
| Apostrophe courbe `’` (U+2019) | *l'ongle*, pas *l'ongle* avec ' droit |
| Guillemets français `«  »` | *« le rituel »* avec espace fine insécable U+202F |
| Tiret cadratin `—` (U+2014) | comme séparateur de phrase ou en titre |
| Tiret demi-cadratin `–` (U+2013) | pour les plages numériques (5–10) |
| Espace insécable avant `: ; ! ?` | obligatoire (point d'exclamation déjà banni) |
| Pas d'abréviation excessive | « Madame » plutôt que « Mme » sauf form |
| Majuscule accentuée | « État », « À propos » avec accents |

## 9. Calendrier des saisons (cohérence éditoriale)

| Saison | Période | Couleur dominante | Mot-clef |
|---|---|---|---|
| **Printemps** | mars-mai | Sauge soft | renouveau |
| **Été** | juin-août | Pétale soft | légèreté |
| **Automne** | sept-nov | Champagne soft | retour |
| **Hiver** | déc-fév | Ciel soft | patience |

Chaque newsletter / billet du journal aligne son ton et sa palette avec la saison en cours.

## 10. Voix par contexte

| Contexte | Voix |
|---|---|
| Journal éditorial | narrative, première personne discrète, paragraphes mesurés |
| Page produit `/kit` | descriptive, factuelle, sans superlatif |
| Email transactionnel | sobre, court, poli |
| Email newsletter | éditorial, ton journal |
| Page checkout | minimaliste, fonctionnelle, rassurante |
| Page contact | hospitalière, mesurée |
| Erreur | factuelle, pas dramatique, sans excuse excessive |
| Réseaux sociaux (Phase 2) | extension de la voix journal, pas plus accessible |

## 11. Mantras à mémoriser

> Trois gestes. Cinq minutes. Une saison.

> La maison est silencieuse. C'est dans ce silence qu'on entend ses ongles.

> Discrétion plutôt que démonstration.

> Le rituel n'est pas un produit. C'est un temps.

## 12. Cas concrets — bonnes vs mauvaises microcopies

| Situation | ❌ Mauvais | ✅ Bon |
|---|---|---|
| Hero `/` | *« Le meilleur soin pour vos ongles ! »* | *« Le rituel ongles, en cinq minutes. »* |
| Hero `/kit` | *« Ajoutez ce kit incroyable à votre panier maintenant »* | *« Le rituel — base, fortifiant, lime. »* |
| Email merci | *« Merci pour votre achat ! 🙏 »* | *« Bienvenue dans la maison. »* |
| Newsletter sujet | *« 🌸 Promo printemps -20% ! »* | *« Printemps, ongles, légèreté. »* |
| Page 404 | *« Oups ! Cette page n'existe pas. »* | *« Cette page n'existe plus dans la maison. »* |
| Toast ajout | *« Produit ajouté ! »* | *« Ajouté au rituel »* |

## 13. Refus de formulations « marketing standard »

FemiGlow se distingue par ce qu'elle **refuse** d'écrire :

- ❌ « Notre best-seller »
- ❌ « Plus de 1 000 clientes satisfaites »
- ❌ « Offre limitée »
- ❌ « Dans la limite des stocks disponibles »
- ❌ « Les premières arrivées sont les premières servies »
- ❌ « Ne ratez pas cette occasion »
- ❌ « Plus que 3 articles en stock »
- ❌ « X personnes consultent cette page »
