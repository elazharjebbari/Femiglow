# F37 — Keyboard shortcuts

## Importance : 🟢 P3

## Objectif
Raccourcis clavier dans le flow publish pour power users.

## Shortcuts
- `Cmd/Ctrl + S` : flush autosave
- `Cmd/Ctrl + Enter` (caption focus) : ouvre dropdown Publier
- `Esc` : ferme dropdown ou dialog
- `Tab` : navigation séquentielle
