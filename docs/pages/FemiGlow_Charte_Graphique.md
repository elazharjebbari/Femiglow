## I — Préambule

### À propos de cette charte

> Comment FemiGlow s'incarne, et pourquoi.

#### Ce que c'est

Une charte graphique est un document de référence. Elle décrit la **grammaire visuelle** d'une marque, ses règles d'usage, et les raisons qui la fondent.

Cette charte s'adresse à toute personne — fondatrice, designer, rédactrice, photographe, partenaire, imprimeur, **développeur d'interfaces** — appelée à produire un visuel ou un texte au nom de FemiGlow.

#### Ce qu'elle n'est pas

Ce n'est **pas un manifeste créatif figé**. Les outils décrits ici ne remplacent pas le jugement éditorial. Ils l'orientent.

Une charte vivante évolue avec la marque qu'elle habille — elle se révise, s'enrichit, se discute. La version 1.0 sera amendée à mesure que FemiGlow gagne ses premiers partenaires.

#### La méthode

Chaque décision visuelle a été ancrée dans la recherche académique compilée par **Nick Kolenda** (kolenda.io) — psychologie cognitive, neurosciences de l'attention, branding du luxe, font psychology.

Mais surtout : **tout part du packaging réel**. La sauge, la pétale poudrée, la calligraphie du wordmark sont déjà là. Cette charte ne les invente pas — elle les codifie.

## II — Fondations stratégiques

> Avant la couleur, la typographie, le pixel, vient l'âme. Ce qui suit définit ce que FemiGlow **est**, et ce qu'elle **n'est pas**.

### II.1 — Essence de marque

> **Mission, vision, valeurs.** Trois piliers pour ancrer toute décision.

#### Mission — Pourquoi nous existons

Rendre accessible aux femmes du Maroc le **rituel japonais de soin des ongles** : sans vernis, sans abrasion, sans compromis. Faire de la beauté un geste vivant — non un masque qu'on applique, mais un éclat qu'on cultive.

#### Vision — Ce vers quoi nous tendons

Devenir la **maison de référence** du soin naturel des ongles au Maghreb, et le partenaire privilégié des instituts qui partagent cette ambition. Construire une marque que l'on transmet — entre amies, entre clientes, entre générations.

#### Valeurs — Ce qui ne se négocie pas

| Valeur     | Signification |
| :--------- | :------------ |
| **Naturel** | Formules sans paraben, sans alcool, sans test animal. |
| **Précision** | Quatre étapes pensées, jamais bricolées. |
| **Rituel** | Un geste lent vaut mieux que dix gestes pressés. |
| **Discrétion** | Le luxe qui ne crie pas. |

### II.2 — Manifeste de la maison

> *Pas une marque de plus. **Une maison.***
>
> *Pas un produit de plus. **Un rituel.***
>
> *Pas une cliente de plus. **Une initiée.***

### II.3 — Archétype — La Connaisseuse

> Une marque a une âme. La nôtre s'appelle **la Connaisseuse**.

#### Mi-Sage, mi-Esthète

Au croisement du **Sage** (savoir, vérité, érudition) et de l'**Esthète** (beauté, élégance, raffinement), la Connaisseuse fuit l'ostentation et préfère le geste juste.

- Elle ne montre pas. Elle **révèle**.
- Elle n'achète pas un produit. Elle **entre dans un rituel**.
- Elle ne suit pas la mode. Elle **cultive la sienne**.

#### Trois axes identitaires

| # | Axe | Définition |
| :- | :-- | :--------- |
| **01** | **Le geste** | Pas la possession. Le rituel. La main qui sait. |
| **02** | **La patine** | Pas le neuf. Le révélé. L'éclat qui revient. |
| **03** | **La discrétion** | Pas le bling. Le détail. Le presque-rien. |

### II.4 — Les deux univers — Particulier & Pro

> FemiGlow s'adresse à deux audiences que tout sépare. **La même palette, les mêmes typographies, le même logo** — mais des dosages différents.

| Dimension | B2C — Rituel | B2B — Précision |
| :-------- | :----------- | :--------------- |
| **Dominante chromatique** | Sauge + Pétale | Crème + Sauge |
| **Photographie** | Mains, gestes | Studio, packaging |
| **Tonalité** | Sensorielle | Experte, factuelle |
| **Densité éditoriale** | Aérée, narrative | Dense, structurée |
| **CTA principal** | « Le rituel » | « Échantillon » |

> **Principe directeur** : ce n'est pas une autre marque, c'est la **même maison qui prend la parole différemment**.

### II.5 — Pour les interfaces graphiques — implications stratégiques

Ces fondations se traduisent concrètement dans toute interface :

| Principe stratégique | Implication UI |
| :------------------- | :------------- |
| **Discrétion** | Pas d'animation flashy, pas de pop-up agressif, pas de countdown |
| **Patience** | Transitions douces (300-800ms), pas de feedback instantané strident |
| **Précision** | Grilles strictes, alignements parfaits, jamais de chaos visuel |
| **Rituel** | Hiérarchie typographique cohérente, espace blanc respiré |
| **Connaisseuse** | Vocabulaire éditorial choisi, jamais de jargon e-commerce |
| **Soustractif (B2C/B2B)** | Une seule design system, deux dosages selon contexte |

## III — Logo

> Le logo est l'**empreinte la plus immédiate**. Il doit respirer, jamais étouffer.

### III.1 — Construction & espace

> Le logo respire. Il a besoin d'**air pour exister**.

#### Anatomie

```
                    x
        ┌───────────────────────────┐
        │                           │
   x    │     FemiGlow              │   x
        │     M A I S O N  D'ÉCLAT  │
        │                           │
        └───────────────────────────┘
                    x
```

#### Unité de mesure — la lettre `x`

| Élément | Définition |
| :------ | :--------- |
| **`x`** | Hauteur de la majuscule **F** du wordmark |
| **Espace de protection** | Aucun élément ne pénètre cette zone (`x` minimum tout autour) |
| **Tailles minimales** | 28 mm en print · 160 px à l'écran |

### III.2 — Système de logo — trois variantes, un seul ADN

> Pour s'adapter à tous les contextes sans jamais se trahir.

#### 01 — Principal — wordmark complet avec tagline

| Élément | Spécification |
| :------ | :------------ |
| **Composition** | `FemiGlow` (Pinyon Script) + `M A I S O N D'ÉCLAT` (Inter SemiBold tracked) |
| **Usage** | Pages d'accueil, packaging extérieur, papeterie principale |
| **Espace minimum** | 2× la hauteur du wordmark |
| **Taille minimale** | 28 mm en print · **160 px à l'écran** |

#### 02 — Signature — monogramme + wordmark

| Élément | Spécification |
| :------ | :------------ |
| **Composition** | Monogramme `Fg` circulaire + wordmark `FemiGlow` |
| **Usage** | En-têtes étroits, bandeaux email, signatures |
| **Espace minimum** | ½ hauteur du monogramme |
| **Taille minimale** | 12 mm en print · **60 px à l'écran** |

#### 03 — Monogramme — `Fg` seul

| Élément | Spécification |
| :------ | :------------ |
| **Composition** | Le monogramme `Fg` dans un cercle fin |
| **Usage** | Favicon, avatar social, sceau, watermark |
| **Espace minimum** | 0,5× le diamètre |
| **Taille minimale** | 8 mm en print · **32 px à l'écran** |

### III.3 — Six mauvais usages à proscrire

> Préserver l'**intégrité du logo**, c'est préserver l'intégrité de la marque.

| # | Erreur | Pourquoi |
| :- | :----- | :------- |
| **01** | Étirer | L'altération des proportions trahit l'origine artisanale. |
| **02** | Pivoter | Le logo s'écrit toujours **horizontalement**. |
| **03** | Changer les couleurs | Encre sur Crème — ou inverse. **Aucune couleur secondaire**. |
| **04** | Ajouter des effets | Pas d'ombre portée, pas de glow, pas de relief. |
| **05** | Placer sur fond chargé | Le logo demande un **aplat neutre**. Pas d'image derrière. |
| **06** | Modifier la typographie | Aucune substitution. Pas de bold, pas de sans-serif lourd. |

### IV.6 — La règle 60 / 30 / 10 — le dosage qui respire

> *« Le luxe n'est jamais saturé. Il est dosé. »* — Principe Kolenda, Luxury Branding

```
┌────────────────────────────────────────────────────────────┐
│                                                            │
│         60% — DOMINANTE              30% — SUPPORT    10%  │
│                                                            │
│         ████████████████████████     ███████████      ███  │
│             SAUGE                     CRÈME          ENCRE│
│                                                            │
└────────────────────────────────────────────────────────────┘
```

| Rôle | Couleur dominante | Fonction |
| :--- | :---------------- | :------- |
| **DOMINANTE (60%)** | Sauge | Structure : fonds, blocs, panneaux, aplats de section. Pose le territoire. |
| **SUPPORT (30%)** | Crème | Respire : marges, espaces, fonds de page. Laisse parler la dominante. |
| **ACCENT (10%)** | Encre | Tranche : titres, lignes de force, signatures. Maximum 10% de la composition. |

### IV.7 — Déclinaison soustractive — B2C & B2B

> **Pas de bichromie radicale.** Une intensité différente, une famille reconnaissable.

#### Particulier · B2C — *Le rituel.*

> La palette riche s'exprime pleinement.

| Couleur | Pourcentage | Rôle B2C |
| :------ | :---------- | :------- |
| **Sauge** | **60%** | Dominante structurante |
| **Crème** | **20%** | Support |
| **Pétale** | **12%** | Accent féminin (vagues, illustrations) |
| **Encre** | **5%** | Ponctuation typographique |
| **Ciel** | **3%** | Touche fraîcheur (pictogrammes step 4) |

> Le ton est **sensoriel, contemplatif, intime**.

#### Partenaire · B2B — *La précision.*

> La palette s'épure. Plus de blanc, plus de grilles.

| Couleur | Pourcentage | Rôle B2B |
| :------ | :---------- | :------- |
| **Crème** | **70%** | Dominante massive |
| **Sauge** | **20%** | Accent unique (filets, badges) |
| **Encre** | **8%** | Densité informationnelle |
| **Champagne** | **2%** | Détail premium (numéros, sceaux) |

> Le ton est **expert, factuel, opérationnel**.

> **L'approche soustractive crée la cohérence** : ce n'est pas une autre marque, c'est la même maison qui prend la parole différemment.

### IV.9 — Règles de dosage strictes pour interfaces

| Règle | Pratique |
| :---- | :------- |
| **Ne jamais saturer** | Aucune surface > 60% de la couleur dominante (Sauge B2C ou Crème B2B) |
| **Champagne ≤ 5% de l'écran** | Réservé aux fleurons, filets de titres, numéros décoratifs |
| **Pétale réservé B2C** | Ne jamais utiliser Pétale dans une interface B2B (cassure de cohérence) |
| **Ciel rare** | Maximum 1-2 occurrences par écran (touche, pas décor) |
| **Pas de gradient** | La maison utilise des **aplats**, jamais de dégradés |
| **Pas d'ombres colorées** | Si ombre, alors `rgba(44, 42, 40, 0.08)` maximum |
| **Pas de transparences saturées** | Préférer un aplat de variation déjà documentée |

## V — Typographie

> **Trois polices, trois rôles.** Pinyon pour la signature, Cormorant pour le titre, Inter pour la voix.

### V.1 — Pinyon Script — la calligraphie du logo

> **Une seule fonction, jamais deux.**

#### Identité

| Attribut | Valeur |
| :------- | :----- |
| **Family** | Pinyon Script Regular |
| **Designer** | Nicole Fally · 2010 |
| **Licence** | SIL Open Font License (libre, redistribution autorisée) |
| **Source** | Google Fonts ou self-host |
| **Usage** | **EXCLUSIF wordmark** |

#### Pourquoi cette police — la main qui dessine

Le wordmark FemiGlow imprimé sur le packaging est une **calligraphie cursive** — pas une typographie classique. Pinyon Script reproduit cet ADN : capitales **F** et **G** ornées de boucles, déliés fins, lettres connectées par un mouvement fluide.

#### Règles d'usage strictes

| Règle | Application |
| :---- | :---------- |
| **Usage exclusif wordmark** | Jamais pour un titre, un sous-titre, un corps de texte |
| **Couleurs autorisées** | Encre `#2C2A28` ou Crème `#FBF8F1` (selon le fond) — aucune autre |
| **Taille minimale** | 12 mm en print · 60 px à l'écran |
| **Pas de déformation** | Jamais étiré, jamais condensé, jamais en italique forcé |
| **Pas d'effet** | Pas d'ombre, de glow, de relief |

> **Sa rareté est ce qui lui donne sa valeur de signature.**

### V.2 — Cormorant Garamond — le titre éditorial

#### Identité

| Attribut | Valeur |
| :------- | :----- |
| **Family** | Cormorant Garamond |
| **Designer** | Christian Thalmann · 2015 |
| **Licence** | SIL Open Font License |
| **Source** | Google Fonts ou self-host |
| **Styles utilisés** | Light · Regular · Italic · Light Italic |
| **Usage** | Titres éditoriaux, sous-titres, citations |

#### Pourquoi cette police — l'élégance serif old-style

Serif old-style avec contraste fort entre pleins et déliés. **Henderson et al. (Marketing Science, 2004)** : les serifs old-style sont perçues comme **élégantes et expertes**. Idéal pour évoquer la maison artisanale.

#### Échelle d'usage

| Style | Taille | Rôle |
| :---- | :----- | :--- |
| Cormorant Light | 22pt | H1 (titres de page) |
| Cormorant Light | 16pt | H2 (titres de section) |
| Cormorant Regular | 12pt | H3 (intertitres) |
| Cormorant Light Italic | 10pt | Italics éditoriaux (citations, sous-titres) |

### V.3 — Inter — le corps fonctionnel

#### Identité

| Attribut | Valeur |
| :------- | :----- |
| **Family** | Inter (rsms.me) |
| **Designer** | Rasmus Andersson · 2016 |
| **Licence** | SIL Open Font License |
| **Source** | Self-host recommandé pour performance |
| **Styles utilisés** | Light · Regular · Medium · SemiBold |
| **Usage** | Corps, UI, kickers, légendes |

#### Pourquoi cette police — la lisibilité écran

Sans-serif géométrique optimisée écran. **Bessemans (Visible Language, 2016)** : les sans-serif modernes sont **plus lisibles** sur écran que les serifs. Idéal pour le contenu fonctionnel.

#### Échelle d'usage

| Style | Taille | Rôle |
| :---- | :----- | :--- |
| Inter Regular | 14pt | Lead (chapôs) |
| Inter Regular | 10pt | Body (texte courant) |

### V.6 — Règles d'usage strictes

| Règle | Pratique |
| :---- | :------- |

## VII — Voix de marque

> **Une seule maison, deux registres.** Sensoriel pour la cliente, factuel pour la professionnelle.

### VII.1 — Voix B2C — *La voix sensorielle.*

#### Trois principes

| Principe | Application |
| :------- | :---------- |
| **Le sens avant le fait** | On parle de douceur, de geste, de rituel — pas de pourcentages. |
| **La phrase courte** | Pas de subordonnées qui s'étirent. Le rythme du tutoiement intérieur. |
| **L'invitation, jamais l'injonction** | « Découvrir le rituel », pas « Acheter maintenant ». |

#### Exemple de microcopy B2C

> *« Ralentir. Quatre gestes. Une main qui retrouve son éclat. »*
> — Tagline Instagram, format B2C

### VII.2 — Voix B2B — *La voix factuelle.*

#### Trois principes

| Principe | Application |
| :------- | :---------- |
| **Le fait avant le sens** | Marges, formats, délais, certifications. Les chiffres avant les adjectifs. |
| **La phrase informative** | Sujet + verbe + complément. Pas de métaphore. Le respect du temps de l'autre. |
| **L'argument, jamais la séduction** | « Demander un échantillon Pro », « Recevoir le tarif partenaire ». |

#### Exemple de microcopy B2B

> *Kit Pro · 12 unités · marge salon 38% · MOQ 6 mois.*
> — Pitch revente, format B2B

### VII.3 — Lexique éditorial — Do & Don't

> *Une marque est aussi ce qu'elle refuse de dire. La discrétion est un acte de positionnement.*

#### On dit (vocabulaire de la maison)

| Mot | Sens |
| :-- | :--- |
| **rituel** | Geste lent, intentionnel. |
| **éclat** | Lumière qui revient — pas neuf. |
| **précision** | Quatre étapes pensées. |
| **naturel** | Sans paraben, sans abrasion. |
| **connaisseuse** | Celle qui sait, sans afficher. |
| **révéler** | Ce qui était déjà là. |
| **patience** | Le temps comme ingrédient. |
| **complice** | Ton entre soi, pas commercial. |
| **partenaire** | Salon, institut — pas « client B2B ». |
| **découvrir** | Verbe d'ouverture, pas d'achat. |
| **maison** | FemiGlow se dit « maison », pas « marque » ou « entreprise ». |
| **initiée** | Cliente qui a complété le rituel. Statut, pas marketing. |
| **avec soin** | Closing récurrent (signature des emails). |

#### On évite (vocabulaire proscrit)

| Mot proscrit | Pourquoi |
| :----------- | :------- |
| **vernis** | FemiGlow n'en pose pas — le mot trahit. |
| **ongles parfaits** | Le perfectionnisme n'est pas la maison. |
| **nail art** | Registre fashion, pas rituel. |
| **révolutionnaire** | Le superlatif est cheap luxury. |
| **incroyable** | Le mot creux des promos. |
| **wow** | Interjection commerciale. |
| **offre flash** | L'urgence est l'ennemie du rituel. |
| **girls** | La maison parle aux **femmes**. |
| **clientes B2B** | On dit **« partenaires »**. |
| **acheter** | On dit « découvrir », « essayer ». |
| **dépêchez-vous** | Pas de pression temporelle. |
| **exclusif !** | Avec point d'exclamation, jamais. |
| **deal**, **promo**, **soldes** | Vocabulaire e-commerce, jamais. |

### VII.4 — Tonalité — règles globales

| Règle | Application UI |
| :---- | :------------- |
| **Pas de point d'exclamation** | Sauf cas exceptionnel justifié |
| **Pas d'emoji** | Jamais (sauf si le contexte conversationnel le rend pertinent — extrêmement rare) |
| **Pas de MAJUSCULES forcées** | Sauf kickers (Inter SemiBold tracking 2px) |
| **Apostrophes typographiques** | Toujours `'` courbe |
| **Guillemets français** | `« »` avec espaces insécables |
| **Tutoiement vs vouvoiement** | **Vouvoiement** par défaut. Le tutoiement est une intimité réservée aux contextes de méditation/rituel. |
| **Pas de jargon SaaS/admin** | Pas de « ticket », « SLA », « priorité », « process » |
| **Closings récurrents** | « Avec soin, » dans les emails — leitmotiv de la maison |

## IX — Annexes

### IX.1 — Checklist de production — 18 points

> Avant chaque livrable, parcourez ces 18 points. **Le diable est dans le détail.**

#### Logo (6 points)

- [ ] Wordmark en **Pinyon Script** — pas de substitution
- [ ] Zone de protection respectée (`x` = hauteur F)
- [ ] Couleur : Encre sur Crème, ou inverse — jamais autre
- [ ] Taille minimum : 28 mm print · 160 px écran
- [ ] Aucun effet : ombre, glow, rotation, étirement
- [ ] Pas sur fond chargé : aplat neutre exigé

#### Couleur & typo (6 points)

- [ ] **Règle 60-30-10** vérifiée (Sauge / Crème / Encre)
- [ ] Champagne ≤ **5%** de la composition
- [ ] B2C : palette riche · B2B : palette épurée
- [ ] Cormorant pour les titres uniquement
- [ ] Inter pour le corps, jamais pour le wordmark
- [ ] Apostrophes typographiques courbes (`'` pas `'`)

#### Voix & système (6 points)

- [ ] Lexique do/don't consulté
- [ ] B2C sensoriel · B2B factuel
- [ ] CTA cohérent avec l'univers (rituel / échantillon)
- [ ] Vague asymétrique, jamais centrée
- [ ] Fleuron en linéature fine, jamais aplat
- [ ] Manifeste relu — la maison parle juste

> **Si un seul de ces 18 points est négligé, l'intégrité de la marque est compromise.** La cohérence est cumulative.

### IX.2 — Glossaire de la maison

| Terme | Définition |
| :---- | :--------- |
| **Connaisseuse** | L'archétype de la maison. Mi-Sage, mi-Esthète. |
| **Encre** | Charcoal chaud `#2C2A28` — pas du noir, pas du bleu. |
| **Étiquette** | Cercle plein avec numéro, mot italique, wordmark. |
| **Fleuron** | Losange champagne entre filets. Séparateur de la maison. |
| **Initiée** | Cliente qui a complété le rituel. Statut, pas marketing. |
| **Pétale** | Rose poudré `#F2CECC` — la vague signature B2C. |
| **Rituel** | Quatre gestes (paste, powder, shine, polish). |
| **Sauge** | Vert pâle `#C5DBC4` — l'ancrage chromatique. |
| **Soustractif** | Approche B2C/B2B : même palette, deux dosages. |
| **Wordmark** | Le logo FemiGlow en Pinyon Script. Toujours seul. |
| **Maison** | FemiGlow se dit « maison », pas « marque ». |
| **Avec soin** | Closing récurrent (signature des emails). |
