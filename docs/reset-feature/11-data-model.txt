PRESERVATION OPTIONS (cocheables dans le wizard)
================================================

Default cochées (préservé) sauf en hard ou explicitement décoché :
  admin_users              (✱ toujours préservé)
  audit_events             (✱ toujours préservé)
  orders + order_items
  leads + lead_events
  chat_lead
  ritual_testimonials + ritual_testimonial_photos + ritual_audit_log

En hard, ces tables sont préservées via :
  1. backup pré-DROP (pg_dump complet)
  2. après migrate vide, on RESTORE uniquement ces tables depuis le backup
     (pg_restore -t table_name) avant de lancer les seeders.

Cf. lib/reset/phases/preserve.ts (sous-phase intercalée entre migrate et seed).
