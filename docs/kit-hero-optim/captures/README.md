## État initial (before-*)

Captures référence prises avant la refonte (Phase 0 du plan). Layout 2 colonnes
desktop, mobile single-column avec CTA sous le fold. Visible dans la conversation
de planification.

Caractéristiques notables observées :
- Image hero unique (packshot studio, sans contexte, sans mains, sans review)
- H1 "Pack FemiGlow", kicker "LE RITUEL"
- Description avec mention "biologiste et formulatrice"
- Prix 199 MAD avec 390 MAD barré + "Économisez 191 MAD" en petit
- CTA noir, full-width, "Commander le rituel"
- Trust row 11 px MAJUSCULES : `PAIEMENT À LA LIVRAISON · RETOUR 14 J · LIVRAISON 48 H`
- Pas de social proof, pas de chips attribut, pas de galerie

À capturer en Phase 7 après application complète du plan. Caractéristiques
attendues :

- Galerie vignettée (4-7 images : produit + contextuel + photos clientes)
- Note `★★★★⯨ 4,8/5 · 287 avis`
- Tagline finissant par "La main se révèle."
- 4 chips : `Sans vernis · Sans UV · Sans acétone · Halal`
- Description retravaillée (continuité d'image, "biologiste" retiré du hero)
- Prix : gap horizontal augmenté, "Économie 191 MAD" 15 px
- Trust row 13 px casse normale : `Livraison offerte · Paiement à la livraison · Retour 30 jours`
- Trust row **au-dessus** du CTA
- CTA en sauge profond `#4A5D4A` avec micro-pulse 600 ms toutes 3-4 s
- Mobile : CTA visible above fold (y < 700 px)
