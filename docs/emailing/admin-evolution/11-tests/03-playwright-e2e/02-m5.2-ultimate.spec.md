# Test ultime M5.2 — Events unifiés

> File: `apps/web/e2e/m5.2-ultimate.spec.ts`

## Scénario

> Envoyer 1 email transactionnel → constater 3+ rows `user_event`
> en DB pour le destinataire (queued, sent, delivered).

```typescript
import { test, expect } from '@playwright/test';

test('M5.2 — Email lifecycle creates user_events', async ({ request }) => {
  const recipient = `m5-2-test-${Date.now()}@example.com`;
  
  // === 1. Trigger email via contact API ===
  const res = await request.post('/api/contact', {
    data: {
      type: 'question',
      name: 'Test User',
      email: recipient,
      message: 'Test message for M5.2 ultimate validation flow.',
      gdprConsent: true,
      newsletterOptIn: false,
    },
  });
  expect(res.ok()).toBe(true);
  
  // === 2. Wait for SMTP delivery webhook (poll up to 30s) ===
  let eventCount = 0;
  const start = Date.now();
  while (Date.now() - start < 30_000) {
    const r = await request.get(`/api/__test__/user-events?email=${recipient}`);
    const events = await r.json();
    eventCount = events.length;
    const hasDelivered = events.some((e: any) => e.event_name === 'email.delivered');
    if (hasDelivered) break;
    await new Promise(r => setTimeout(r, 1000));
  }
  
  // === 3. Verify ===
  expect(eventCount).toBeGreaterThanOrEqual(3); // queued, sent, delivered (au moins)
  
  const events = await (await request.get(`/api/__test__/user-events?email=${recipient}`)).json();
  const eventNames = events.map((e: any) => e.event_name);
  
  expect(eventNames).toContain('email.queued');
  expect(eventNames).toContain('email.sent');
  expect(eventNames).toContain('email.delivered');
});

test('M5.2 — Web tracking event ingestion', async ({ request }) => {
  const sessionId = `session-${Date.now()}`;
  const email = `webtrack-${Date.now()}@example.com`;
  
  // Simulate add_to_cart from website
  await request.post('/api/tracking/events', {
    data: {
      event_name: 'cart.added',
      session_id: sessionId,
      email,
      properties: { productId: 'XYZ', total: 100 },
    },
  });
  
  await new Promise(r => setTimeout(r, 500));
  
  const events = await (await request.get(`/api/__test__/user-events?email=${email}`)).json();
  expect(events).toHaveLength(1);
  expect(events[0]).toMatchObject({
    event_name: 'cart.added',
    source: 'web',
    properties: expect.objectContaining({ productId: 'XYZ' }),
  });
});
```

## Bridges couverts

- email_webhooks (stalwart) → email.queued, email.sent, email.delivered, email.bounced
- web_tracking → cart.added, page.viewed, etc.
- server_actions → order.placed, lead.created
- admin_actions → lead.status_changed, etc.

## Couverture

- ✓ Email lifecycle → 3+ events
- ✓ Web tracking → 1 event
- ✓ Source correctement attribuée
- ✓ Properties préservées
