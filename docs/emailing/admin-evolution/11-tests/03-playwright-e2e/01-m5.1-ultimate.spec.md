# Test ultime M5.1 — Inbox transactionnelle

> File: `apps/web/e2e/m5.1-ultimate.spec.ts`
> Critère d'acceptance M5.1.

## Scénario

> Un admin connecté retrouve, en moins de 60 secondes, un email
> d'un destinataire précis, retry, sauvegarde la vue, et exporte en CSV.

```typescript
test('M5.1 — Cockpit transactional ultimate', async ({ page }) => {
  test.setTimeout(60_000);
  
  // Pré-condition : seed 200 emails dans email_outbox, 1 failed pour
  // 'lookup@example.com'
  
  await page.goto('/admin/emails/transactional');
  
  // === KPI Header visible ===
  await expect(page.locator('[data-testid="kpi-delivered"]')).toBeVisible();
  await expect(page.locator('[data-testid="kpi-failed"]')).toBeVisible();
  
  // === Cmd-K search ===
  await page.keyboard.press('Meta+K');
  await page.fill('[role="combobox"]', 'to:lookup@example.com');
  await page.keyboard.press('Enter');
  
  // === Verify filter applied ===
  await expect(page.locator('table tbody tr')).toHaveCount(1);
  await expect(page.locator('text=lookup@example.com')).toBeVisible();
  
  // === Retry ===
  await page.click('table tbody tr [aria-label="Actions"]');
  await page.click('text=Retry');
  await expect(page.locator('text=retried')).toBeVisible();
  
  // === Save view ===
  await page.keyboard.press('Meta+K');
  await page.click('text=Save current view as...');
  await page.fill('input[name="view-name"]', 'Lookup failures');
  await page.click('button:has-text("Save")');
  
  // === View appears in sidebar ===
  await expect(page.locator('text=Lookup failures')).toBeVisible();
  
  // === Export CSV ===
  const [download] = await Promise.all([
    page.waitForEvent('download'),
    page.click('button:has-text("Export CSV")'),
  ]);
  expect(download.suggestedFilename()).toMatch(/^emails-.*\.csv$/);
});
```
