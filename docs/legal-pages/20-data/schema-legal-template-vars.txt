TABLE public.legal_template_vars (NOUVELLE)
=============================================
Key/value store pour les variables substituées dans le contenu MD.

Colonne          | Type                         | Notes
-----------------|------------------------------|------------------------
key              | text PK                      | COMPANY_NAME, ICE, RC, ...
value            | text                         | "FemiGlow", "001234567890123", ...
label            | text NOT NULL                | Libellé admin (FR)
description      | text                         | Aide / format attendu
is_required      | boolean NOT NULL DEFAULT TRUE| Bloque publish si null/empty
sensitive        | boolean NOT NULL DEFAULT FALSE| Masqué dans logs si TRUE
updated_at       | timestamp with time zone NOT NULL DEFAULT now()
updated_by       | text                         | FK admin_users.id

CONTRAINTES
- PK (key)
- CHECK (key ~ '^[A-Z][A-Z0-9_]*$' AND length(key) BETWEEN 2 AND 40)
- CHECK (value IS NULL OR length(value) <= 1000)

UTILISATION DANS LE CONTENU MD

```markdown
**{{COMPANY_NAME}}** est édité par {{DIRECTOR_NAME}}, basée à
{{COMPANY_ADDRESS}}.

- **RC** : {{COMPANY_RC}}
- **ICE** : {{ICE}}
- **Email** : {{COMPANY_EMAIL}}
- **Téléphone** : {{COMPANY_PHONE}}
```

Le renderer (legalRenderer.render(text)) substitue les `{{VAR}}` au runtime.
Si une variable est manquante (NULL, vide, ou clé inconnue) :
- En édition admin : highlight rouge dans la preview
- En public : rendu = "[variable non remplie : COMPANY_RC]" ou fallback

MIGRATION
---------
CREATE TABLE legal_template_vars (
  key text PRIMARY KEY CHECK (key ~ '^[A-Z][A-Z0-9_]*$' AND length(key) BETWEEN 2 AND 40),
  value text CHECK (value IS NULL OR length(value) <= 1000),
  label text NOT NULL,
  description text,
  is_required boolean NOT NULL DEFAULT TRUE,
  sensitive boolean NOT NULL DEFAULT FALSE,
  updated_at timestamp with time zone NOT NULL DEFAULT now(),
  updated_by text REFERENCES admin_users(id) ON DELETE SET NULL
);
