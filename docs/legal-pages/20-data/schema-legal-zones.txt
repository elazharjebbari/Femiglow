TABLE public.legal_zones (NOUVELLE)
=====================================
Catalogue des zones du site où peuvent apparaître des liens vers les
pages légales. Liste fermée (admin choisit parmi les zones disponibles).

Colonne                | Type                       | Notes
-----------------------|----------------------------|------------------------
key                    | text PK                    | footer-main, cookie-banner, ...
label                  | text NOT NULL              | Libellé admin (FR)
description            | text                       | Aide pour l'admin
max_items_recommended  | integer NOT NULL DEFAULT 5 | Hint UI (warning si dépassé)
is_required            | boolean NOT NULL DEFAULT FALSE | Zone qui DOIT avoir au moins 1 page (footer-main)
display_order          | integer NOT NULL DEFAULT 0 | Ordre dans la liste admin
created_at             | timestamp with time zone NOT NULL DEFAULT now()

CONTRAINTES
- PK (key)
- CHECK (key ~ '^[a-z0-9-]+$' AND length(key) BETWEEN 2 AND 50)
- CHECK (max_items_recommended BETWEEN 1 AND 20)

MIGRATION
---------
CREATE TABLE legal_zones (
  key text PRIMARY KEY CHECK (key ~ '^[a-z0-9-]+$' AND length(key) BETWEEN 2 AND 50),
  label text NOT NULL,
  description text,
  max_items_recommended integer NOT NULL DEFAULT 5 CHECK (max_items_recommended BETWEEN 1 AND 20),
  is_required boolean NOT NULL DEFAULT FALSE,
  display_order integer NOT NULL DEFAULT 0,
  created_at timestamp with time zone NOT NULL DEFAULT now()
);
