LÉGENDE :
  🎯 = event marqué isConversion=true dans le catalog
  ⚡ = au moins une cellule isCustom=true
  📝 = au moins une cellule avec notes
  —  = mappedName null (pas de dispatch)

INTERACTIONS :
  - Click cellule → ouvre le popover éditeur (à la place)
  - Arrow keys naviguent entre cellules en mode focus (clavier-first)
  - Bouton "Tester" → ouvre MappingTestModal
  - Bouton "Sauvegarder" → POST PUT → redirect vers /v4 (la nouvelle version)
  - Si dirty + leave page → confirm beforeunload
  - Filtres "Conversion only" cache les rows isConversion=false

A11Y :
  - <table role="table">, <caption>, <thead>, <tbody>
  - Cellule = <td>, contient un <button> qui ouvre le popover (focusable)
  - Popover = <dialog> ou role="dialog" + aria-modal
  - Focus trap dans le popover, Esc ferme
  - Tab cycle normalement après fermeture du popover
