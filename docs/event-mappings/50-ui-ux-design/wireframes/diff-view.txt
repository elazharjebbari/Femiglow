LÉGENDE :
  🟢 = Cellule ajoutée (vide → non-vide)
  🔴 = Cellule supprimée (non-vide → vide)
  🟡 = Cellule modifiée (non-vide → non-vide différent)
  ✓  = Inchangé

MODE INLINE :
  Affichage condensé sur 1 colonne. Cellule modifiée :

  🟡 form_start × meta
     - form_start_v1 (custom)
     + form_start (custom)

  Style "git diff" : ligne barrée rouge / ligne verte underline.

INTERACTIONS :
  - Click sur une ligne → scroll smooth + highlight 3s
  - Toggle "Modifications uniquement" : filtre les ✓
  - Filter Provider : ne montre que les cellules d'un provider
  - "Adopter v3 et l'activer" : raccourci pour activate sans repasser par liste
