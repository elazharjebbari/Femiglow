# 50.3 — Accessibilité (WCAG AA)

## Cibles

- WCAG 2.1 niveau AA minimum
- 0 violation critical/serious sur axe-core
- Navigation 100% clavier
- Lisible avec lecteur d'écran (NVDA, JAWS, VoiceOver testés)

## Règles par composant

### MappingVersionsList
- Liste = `<ul role="list">` avec items `<li>`
- Badges status = `<span aria-label="Version active">`
- Actions row = `<menu>` ou groupe de `<button>` avec `aria-label` explicite par bouton (pas juste icône)
- Compare = checkbox avec `<label>` "Comparer v3 avec une autre"

### MappingMatrix (table pivot)
- `<table role="table">` (explicit pour ne pas perdre la sémantique sur grandes tables)
- `<caption>` "Mappings event vers vendors pour la version {name}"
- `<thead><th scope="col">` pour les providers
- `<th scope="row">` pour les events (col gauche)
- Cellule éditable = `<td>` + `<button>` à l'intérieur (pas `tabIndex` sur td direct)
- Bouton cellule : `aria-label="Mapping de purchase pour Meta : Purchase, custom event activé"` (verbeux mais clair pour SR)
- Navigation : flèches `←↑↓→` entre cellules (équivalent Excel)
- Tab cycle : col gauche events → contenu → col droite actions
- Sticky header/col avec `aria-describedby` pour le contexte

### MappingCellEditor (popover/dialog)
- `<dialog>` natif OU `role="dialog" aria-modal="true"`
- Focus trap : Tab cycle dans le popover, Shift+Tab inverse
- Esc ferme et restore focus sur la cellule
- `aria-labelledby` pointe vers le titre "event × provider"
- Input mappedName : `aria-describedby` pointe vers le hint regex + error message
- Validation live : `aria-live="polite"` sur la zone d'erreur

### MappingCreateWizard
- `role="dialog" aria-modal="true"`
- Step indicator : `<ol>` avec `aria-current="step"` sur l'étape active
- Transition step : `aria-live="polite"` annonce "Étape 2 sur 3 : Nom et description"
- Boutons Back/Next : `aria-keyshortcuts="Enter Escape"`
- Focus auto sur premier input de chaque step

### MappingTestModal
- Résultats par provider : liste `<ul>` avec icônes décoratives `aria-hidden="true"` et texte alternatif
- Ex : "✅ Meta — Purchase, standard event" lu correctement

### MappingDiffViewer
- Tableau de diff avec `<table>` sémantique
- Indicateurs visuels (🟢🔴🟡) **toujours doublés de texte** : "Ajouté", "Supprimé", "Modifié"
- Pas de couleur seule comme signal (cf. WCAG 1.4.1)
- Contrast colors validés AA (4.5:1 pour text, 3:1 pour graphiques)

### Toasts
- `role="status"` (info/success) ou `role="alert"` (error)
- `aria-live="polite"` (info/success) ou `aria-live="assertive"` (error)
- Auto-dismiss 5s + bouton fermeture manuelle (icône `aria-label="Fermer notification"`)

## Navigation clavier — keyboard shortcuts

| Touche | Action | Context |
|---|---|---|
| `Tab` | Element suivant | Global |
| `Shift+Tab` | Element précédent | Global |
| `Enter` | Activer bouton / submit / éditer cellule | Liste, matrice |
| `Esc` | Fermer modal / popover / annuler édition | Modales, popovers |
| `←↑↓→` | Naviguer dans la matrice | MappingMatrix |
| `Ctrl+S` (ou Cmd+S) | Sauvegarder | Éditeur |
| `Ctrl+/` | Ouvrir search | Éditeur |
| `Ctrl+K` | Quick action palette (V2) | Global |
| `?` | Help shortcuts modal | Global |

## Contraste

Vérifications minimum :
- Texte primaire (`stone-900` sur `stone-50`) : ratio 16:1 ✅
- Texte secondaire (`stone-600` sur `stone-50`) : ratio 6.5:1 ✅
- Texte sur badges : tous validés AA (cf. design-tokens.md)
- Border `stone-200` sur `stone-50` : pas requis AA mais OK perçu
- État focus : ring 2px `stone-900` (suffisant)

## Lecteurs d'écran — tests manuels

Avant deploy, tester avec :
- VoiceOver macOS (Cmd+F5)
- NVDA Windows
- Mobile : VoiceOver iOS sur l'éditeur si responsive prévu

Scénarios à valider :
- Annoncer la matrice et lire 1 cellule
- Navigate dans le wizard avec lecteur d'écran seul
- Soumettre une édition de cellule avec lecteur d'écran
- Comprendre un toast d'erreur sans voir la couleur

## Erreurs sur écrans tactiles

- Touch targets ≥ 44x44px (cellules trop petites en matrice → pop-over plein écran sur mobile V2)
- Drag & drop évité (utiliser boutons explicites)
- Pas de hover-only revealed actions (touch n'a pas de hover)

  const { container } = render(<MappingVersionsList ... />);

  expect(results).toHaveNoViolations();
});

import AxeBuilder from '@axe-core/playwright';

test('axe-core 0 violation sur /admin/tracking/events/mappings', async ({ page }) => {
