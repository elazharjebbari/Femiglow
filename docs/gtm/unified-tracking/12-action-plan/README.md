# 12 — Plan d'action

Plan d'action opérationnel : phases d'exécution, qui fait quoi, quand, et critères pour passer à la phase suivante.

Le **plan de conception** (section 10) répond "Quoi & Pourquoi".  
Le **plan de développement** (section 11) répond "Comment & Combien de temps".  
Le **plan d'action** répond "Quand & Avec qui & Comment décider d'avancer".
