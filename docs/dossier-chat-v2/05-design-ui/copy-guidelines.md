# Copy guidelines — Voice, tone, microcopy

> La voix FemiGlow est **intime, féminine, jamais sucrée, jamais froide**. On parle à une amie cultivée, marocaine, qui mérite des produits et des explications de qualité.

## Voice attributes

| Attribut | Définition | Exemple ✅ | Anti-exemple ❌ |
|---|---|---|---|
| Intime | On tutoie/vouvoie selon contexte, mais on est proche | "Comment je peux vous aider ?" | "Quelle est votre requête ?" |
| Compétente | On sait, on rassure, sans condescendance | "Le pack est à 199 dh." | "Pour information, le prix s'élève à 199 dh." |
| Concrète | Pas de bullshit marketing | "Livraison à Casa : 24h, 30 dh." | "Une expérience de livraison exceptionnelle." |
| Chaleureuse | Empathie sans sirop | "Je comprends, c'est important." | "OMG je suis trop désolée 😢😢😢" |
| Bilingue native | Le code-switching fr ↔ darija est natif | "Bonjour ! Chhal nkhdem m3ak ?" (mix possible) | Tout traduire littéralement |

## Règles de microcopy

### 1. Pas de jargon

| Jargon ❌ | À dire ✅ |
|---|---|
| "Veuillez patienter pendant l'initialisation de votre session." | "Un instant, je me prépare..." |
| "Erreur 502 Bad Gateway." | "On a un petit souci technique." |
| "L'authentification a échoué." | "Désolée, je n'ai pas réussi à vous identifier." |
| "Soumettre le formulaire" | "Envoyer" |
| "Annuler l'opération" | "Annuler" |

### 2. Bénéfice, pas feature

| Feature ❌ | Bénéfice ✅ |
|---|---|
| "Système multi-canal cross-platform" | "Recevez votre réponse partout." |
| "Réponses générées par IA" | "Une réponse personnalisée pour vous." |
| "Streaming SSE temps réel" | "Voyez la réponse arriver." |

### 3. Action verbs en CTAs

| ❌ | ✅ |
|---|---|
| "Soumettre" | "Envoyer", "Continuer", "Commander" |
| "Cliquer ici" | "Voir le Pack", "Découvrir" |
| "OK" | "C'est compris", "Oui je veux" |

### 4. Empathie sans excès

```
Frustration utilisateur :
❌ "OMG je suis tellement désolée ! Je comprends parfaitement votre frustration et je vais vraiment faire de mon mieux !"
✅ "Je vous comprends. Voyons ensemble ce qu'on peut faire."
```

### 5. Confirmation = courte + concrète

```
❌ "Votre formulaire a été soumis avec succès. Nous vous remercions pour votre intérêt envers FemiGlow et nous reviendrons vers vous dans les plus brefs délais."
✅ "Merci ! On vous rappelle dans la journée."
```

## Anti-patterns rédactionnels

### ❌ Cliché marketing
- "Une expérience exceptionnelle"
- "Solution révolutionnaire"
- "Premium quality"
→ Bénéfice concret à la place.

### ❌ Politesse excessive
- "Voudriez-vous bien me communiquer votre nom et prénom s'il vous plaît, ma chère ?"
→ "Comment vous appelez-vous ?"

### ❌ Émojis avalanche
- "Bonjour 😊✨💖 super que vous soyez là 🥰🌸"
→ Max 1 emoji par message, **dans le contenu** (pas la salutation).

### ❌ Faux compliment
- "Excellent choix !"
→ Pas commenter le choix utilisateur ; répondre à sa question.

### ❌ Pseudo-darija anglicisée
- "Awesome wallah hada Pack zwin"
→ Soit darija natif "Hada Pack zwin bzaf, ghan'fhmek 3lih", soit FR pro.

## Localisation — Conseils techniques

### Darija (ar-MA) en chat

- On utilise la **graphie latine** par défaut (plus rapide à taper, plus lue).
- Conserver les chiffres pour les sons inexistants en alphabet latin : `3` (ع), `7` (ح), `9` (ق), `gh` (غ).
- Pas de mélange systématique avec FR ("c'est cher bzaf") : c'est OK ponctuel, pas en plain message.

### Arabe (ar) classique

- Forme **moderne MSA**, pas classique littéraire.
- `ة` à la fin des féminins (pas `ت`).
- Ponctuation arabe : `،` `؟` `؛` (pas `,` `?` `;`).

### Français

- **Tutoiement** dans la mesure du possible (la voix FemiGlow est intime).
- Sauf cas formel (lead B2B, RGPD) → vouvoiement.
- Pas de "Madame", "Monsieur" sauf email transactionnel.

## Process de validation copy

1. **Brouillon** par dev/content (champ markdown).
2. **Revue native** : un locuteur natif lit le AR/AR-MA (Naima ou Yasmine).
3. **Test in-context** : voir la phrase dans le chat live (Storybook ou env preview).
4. **Validation PO** : Selma OK/NOK.
5. **Publish** via workflow draft → review → published.
