TABLE public.tracking_providers · CHAMPS google_ads après V1
=============================================================
Pour le chantier 1, on EXTEND `config` JSONB avec :

config.googleAdsCustomerId      | string (10 chiffres)
config.googleAdsDeveloperToken  | string (chiffré, dans config car volumineux)
config.googleAdsRefreshToken    | string (chiffré)
config.googleAdsConversionActions | { [eventName]: { actionLabel, category } }

Exemple :
{
  "googleAdsCustomerId": "7082602195",
  "googleAdsConversionActions": {
    "purchase": { "actionLabel": "AbCdEf123Abc", "category": "purchase" },
    "lead_capture": { "actionLabel": "XyZ789xyZ123", "category": "lead" },
    "phone_call_initiated": { "actionLabel": "PqR456pqR123", "category": "contact" }
  }
}

NOTE : les tokens (developerToken, refreshToken) DOIVENT être chiffrés au
repos. Préférer une colonne séparée `google_ads_oauth_credentials` (chiffrée
AES-GCM) à l'embedding dans config JSONB.
