STOCKAGE GTM CONFIG VERSIONS
=============================
Pas de table dédiée — stocké dans tracking_settings sous la clé
`gtm.config_versions`.

Format JSONB :

    { "id": "uuid-v1", "name": "v1 — initial", ... }

}

POLITIQUE
- max 50 versions, FIFO, jamais supprime l'active
- clonedFrom permet de tracer la chaîne d'héritage (édition)
- pas de FK vers tracking_providers : snapshot indépendant

GET / SET
---------
const state = await trackingSettingsRepo.get('gtm.config_versions');
state.versions.push(newVersion);
await trackingSettingsRepo.set('gtm.config_versions', state);

CRUD
----
create(version)    → ajoute, ne change pas activeId
activate(id)       → set activeId = id
clone(id, newName) → duplique, NEW id, clonedFrom = id, NOT activated
remove(id)         → drop si !active
update(id, patch)  ❌ NE PAS IMPLÉMENTER — toujours créer une nouvelle version
                    pour préserver l'audit
list()             → versions trié par createdAt DESC
get(id)            → un seul
